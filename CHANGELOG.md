# Changelog

All notable changes to altaria are documented here. The project uses
[semantic versioning](https://semver.org/).

## [1.0.0] - 2026-11-15

First public release.

### Listen

- Search tracks, playlists and artists, with pagination and deduplication.
- Browse the public SoundCloud charts.
- Play a track, a playlist or an artist, with queue, previous/next and seek.
- Background playback with lock-screen artwork and transport controls.
- Pause for calls and headphone unplug, then resume.
- No SoundCloud account, ads, feed, downloads or offline catalogue.

### Train

- 200+ seeded movements with muscle group, equipment and original cues.
- Custom movements and unlimited routines with targets, rest and supersets.
- Workout logging for working, warm-up, drop and failure sets, including
  bodyweight, time, distance, RPE and per-set notes.
- Previous performance while logging, mid-workout movement changes and a
  superset flow.
- A rest timer with per-exercise defaults, +15/-15/skip, an in-app countdown and
  a separate notification channel that never interrupts music.
- Plate, warm-up and 1RM calculators.
- History, progress records, body measurements and progress photos, all local.
- kg/lb display, keep-screen-awake, notification permission and JSON/CSV
  backup. No account, paywall, trial, ad or network requirement for training.

### Release

- Android release APK built with Flutter 3.50 / Dart 3.14.
- Unsigned iOS IPA produced by the GitHub Actions workflow when it runs.
